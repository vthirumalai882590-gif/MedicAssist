# MediAssistant — Master Build (v2)

> MediAssistant is an agentic clinical documentation system that investigates fragmented synthetic patient records, detects and prioritizes uncertainty, traces its provenance, generates verification workflows, adapts when underlying information changes, and produces a validated draft that always remains under human clinician review.

## System Architecture & Features
- **Pure Agentic Workflow**: Goal → Decision → Action → Observation → Adaptation → Verification
- **Clinical Truth Graph**: In-memory mutable patient graph with node metadata & diff detection
- **CAUT Engine**: Context-Aware Uncertainty Triangulation formula `(0.4 × workflow) + (0.3 × accessibility) + (0.3 × safety)`
- **PGV Map**: Provenance-Gap Visualization with dynamic node-link graph rendering
- **SVWG Generator**: Deterministic rule-based verification checklist generator
- **Adaptive Evidence Loop**: Real-time environment change invalidation & replanning (`[ Simulate New Data ]`)
- **Safety Architecture**: Code-level assertion enforcing `synthetic_only: true` and `human_review_required: true`
- **5-Page Clinical Dashboard**: React + Vite workspace, patient detail, provenance viewer, verification manager, evaluation dashboard

## Quickstart Setup

### Backend (FastAPI + PyTest)
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
Run Evaluation Suite:
```bash
cd backend
pytest tests/test_agent_eval.py -v
```
> **Note on Evaluation Metrics:** `backend/app/data/eval_results.json` is a test-run artifact automatically regenerated by running the PyTest suite (`test_agent_eval.py`). The Evaluation page reads live metric scores directly from this test execution output.


### Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```

### Docker Compose Deployment
```bash
docker-compose up --build
```
